# RFC: Strict Rust profile instead of a new language

Body: [docs/PLAN.md](../PLAN.md) (Plan A, drafted by a planning agent, adopted by the owner on 18 November 2026).

Decision: bake Sovel's ideas into Rust crates, lints and a checker instead of building a new language, pilot it on agent-written code and adopt it in the owner's projects. The defect-reduction pilot did not establish a benefit (see [STATUS.md](../STATUS.md)); the product was repositioned by [2026-11-19-discipline](2026-11-19-discipline.md), which owns the direction from then on.
